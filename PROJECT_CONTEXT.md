# Projeto

Cliente: Erick Garcia

Objetivo:
Criar site profissional para posicionar Erick Garcia em duas áreas comerciais principais:
1. Social Media
2. Sites Profissionais

Domínio:
erickgarciaeditor.com.br

Assinatura comercial principal:
ERICK GARCIA
SOCIAL MEDIA E SITES

Público:
Profissionais autônomos, especialistas, criadores de conteúdo, líderes religiosos, barbearias, confeiteiras, restaurantes, representantes comerciais, comércios locais, pequenas e médias empresas e clientes remotos de todo o Brasil.

Conversão:
WhatsApp e solicitação de proposta.

Stack:
React + TypeScript + Vite + CSS estruturado.
Sem Supabase/admin na primeira versão.

Páginas planejadas:
- Home
- Cases
- Projetos de sites
- Política de Privacidade
- Termos de Uso
- 404

Design system:
Visual escuro, grafite, branco quente, azul elétrico como destaque, tipografia forte nos títulos e interface legível.

Integrações:
Inicialmente nenhuma integração backend.
Formulário será definido depois.

Assets:
Google Drive será usado como inbox.
Site final usará arquivos locais otimizados em public/assets/.
